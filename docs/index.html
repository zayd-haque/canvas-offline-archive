What you can do

A course archive you can actually use.

Canvas Offline Archive turns captured materials into a browsable local library. Capture the categories you want, then find and open them.

▦

Choose what to capture

Select modules, files, syllabus, assignments, announcements, and other available Canvas categories. Published content determines what can be saved.

⌕

Search local files

Search filenames and extracted text. On-device OCR can add text from scanned PDFs when the Mac supports it.

▤

Browse familiar views

Use Dashboard, Courses, Timeline, and Folders. Preview supported files and reveal originals in your system file manager.

↻

Keep courses current

Rescan a course when you are online and signed in. Existing archives remain available locally between updates.

◇

Choose how files are sorted

Start with built-in keyword rules, select a local Ollama model, or use your own Gemini API key.

⌂

Keep the library on your computer

The app serves its interface locally. Your downloaded courses and search cache live on your computer.

Inside the app

Find the course detail you need.

The dashboard opens your saved courses and gives you shortcuts to modules, files, timelines, and the course folder. Each course brings the captured material together in views built for reading and finding things.

Assignments, grades, and syllabus

Review captured due dates and feedback. Open the original syllabus PDF when available, or use the structured course views.

Announcements and timeline

Read saved announcements in order and scan a timeline of captured course milestones.

Search and preview

Search from the header, narrow full results by material type, and open a local preview or reveal the file in your file manager. Results come from your saved archive, not live Canvas.

How it works

Capture once. Return anytime.

01 · SET UP

Choose your directory

The optional in-app guide helps you pick a course folder and organization method. You can skip and reopen it later.

02 · CAPTURE

Sign in to Canvas

Use your own authorized account, choose a course URL and categories, and let capture finish while online.

03 · USE OFFLINE

Open your archive

Browse saved files and search indexed content without Canvas. Fresh captures and rescans still need internet.

Get started

Install on Mac or Windows.

Choose your platform's ZIP and double-click its launcher. The first setup installs Python dependencies and opens the local app in your browser.

  1. Install Python 3.14 for your computer. First setup requires internet.
  2. Download the Mac ZIP or Windows ZIP, then extract it into a folder you control.
  3. Open the extracted canvas-offline-archive folder. On Mac, double-click Open Canvas Offline Archive.command. On Windows, double-click Open Canvas Offline Archive Windows.cmd. Keep the command window open while using the app.
  4. Follow the optional in-app setup guide. Your institution may ask for browser sign-in or 2FA during capture.

Pick an organization method.

Choose during setup and change it later. The app does not silently switch providers.

NO EXTRA ACCOUNT

Keyword rules

Start without an AI key or downloaded model. Classification uses local filename and course-text patterns.

LOCAL MODEL

Ollama

Install Ollama and a supported model yourself. Classification runs on your computer; speed depends on your hardware.

CLOUD OPTION

Gemini

Enter your own Google AI Studio API key. Eligible course excerpts and filenames, including submitted coursework on rescans, are sent to Google.

Gemini free-tier privacy: Google says content submitted through unpaid Gemini API quota, and the responses, may be used to improve its products and reviewed by humans. Do not use the free tier for sensitive, confidential, or personal course material. Choose Keyword rules or Ollama to keep classification content local. The app's Gemini rate-tier setting changes request pacing only; it does not change your Google billing or data-use terms. Read Google's Gemini API terms.
Clear boundaries

Know what works offline.

Already captured courses

Open saved files, browse the archive, and search its local index without Canvas. Apple Vision OCR for scanned PDFs is available on supported Macs; Windows does not have OCR in this release.

New captures and rescans

These connect to Canvas and require your own valid login. Gemini classification also connects to Google when selected.

The release download contains app code and blank configuration only. It does not include another person's courses, browser profile, API key, or search cache. Your data is created on your computer after installation.

Questions

Before you install

Does the app run on this website?

No. This page explains and distributes the app. After installation, its Python server runs on your computer at 127.0.0.1:8000 and opens in your browser.

Will I need a command line?

Double-click the included Mac or Windows launcher; you do not need to type a command. Its terminal window shows installation and server progress.

Is every Canvas course guaranteed to copy completely?

No. Availability depends on your institution's authentication, permissions, published material, and file types. The fixture suite passes, but check live capture with your own course.

Can I use it without an AI account?

Yes. Choose Keyword Heuristics. Ollama is another local option if you install a supported model.

Where do my files go?

You choose a destination in the app. Browser authentication stays in a private profile on your computer; search indexes and previews are local caches. Review the Mac guide or Windows guide before sharing an archive.

Compatibility note: fixture tests pass and a Windows VM smoke test covered startup and the update check. Live Canvas capture varies by institution, and a complete Windows update installation has not been tested on Windows.
